# 🎧 Soundify — Luxury Studio Acoustics & ANC Storefront

Soundify is a high-end, luxury e-commerce web application engineered for audiophiles, featuring precision acoustic monitors, immersive 3D/360° product previews, and a cyber-tech aesthetic inspired by premier high-end brands.

---

## ✨ Key Features

- **3D & 360° Product Showcase:** Interactive frame-cycling rotation on the collection grid and a dedicated live Three.js 3D inspection model inside the Quick View modal.
- **Advanced Collection & Filtering:** Multi-layered filters by category, brand matrix, live search, and dynamic price range slider with loading skeletons.
- **Global State Management:** Context API with `localStorage` persistence for Cart, Wishlist, and User Profiles.
- **Slide-Over Drawers & Toasts:** Smooth slide-over drawers for both Cart and Wishlist items, accompanied by animated toast notification stacks.
- **Modern Typography & Aesthetic:** Styled with Tailwind CSS using custom `Outfit` and `Plus Jakarta Sans` typography, paired with dark glassmorphic design and purple/cyan neon accents.
- **Client-Side Routing:** Full SPA navigation powered by `react-router-dom` for shareable URLs and seamless browser history.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Animations:** GSAP (GreenSock)
- **3D Graphics:** Three.js / React Three Fiber
- **Icons & UI:** Lucide React
- **Routing:** React Router DOM
